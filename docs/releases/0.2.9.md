# Codex Board 0.2.9

2026-10-17

Automation final replies now have a shared instruction limiting them to three short bullet points and 40 words total. Runs without relevant changes should return a single short sentence. Reports omit preambles, task recaps, narration and generic recommendations while retaining material failures and uncertainties.

The instruction applies when a turn starts, including existing and queued automations. Saved prompts and explicitly requested deliverables remain unchanged. Desktop and mobile receive the same result from the PC backend; the change requires the new Windows application, not a mobile OTA update.
