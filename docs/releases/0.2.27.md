# Codex Board 0.2.27

2026-10-27

Mobile customer boards now match Windows project paths consistently and wait for customer ownership to save before showing a newly created or forked conversation.

Desktop and mobile now store model and turn settings per conversation. Existing board settings remain the default for conversations without an explicit choice; the Windows gateway persists and shares individual selections.

Automation reports no longer cut valid summaries or noteworthy items in mid-sentence when saved or shown in notifications. Reports already truncated by an older backend are not reconstructed automatically; the original conversation remains available.

Mobile source version and OTA runtime stay at 0.2.8 and 0.2.2 respectively, so compatible installed binaries can receive this update. The new per-conversation settings endpoint and report fix require the 0.2.27 Windows backend.
