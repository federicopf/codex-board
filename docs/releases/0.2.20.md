# Codex Board 0.2.20

2026-10-23

Mobile chat history now loads the newest ten timeline entries from the local rollout file and fetches older entries on demand. The gateway avoids loading the full transcript for these requests. Mobile refreshes only when the selected thread completes or resumes work.

Fixed customer entries in the desktop project sidebar so expanded customer lists wrap and remain visible; project path comparison now uses the shared normalization helper.

The mobile JavaScript changes require an EAS Update to reach installed mobile clients. No OTA was published as part of this Windows installer release.
