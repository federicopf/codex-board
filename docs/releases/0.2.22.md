# Codex Board 0.2.22

2026-10-23

Customers can now be deleted from the desktop and mobile project navigation. Threads owned by a deleted customer remain available as generic project conversations.

Image attachments sent in chat are now saved locally and exposed to Codex as file paths, so automations and follow-up requests can use the actual image file rather than only its chat preview. Images sent before this update need to be sent again to create the local file.

The mobile customer and image attachment changes are included in the OTA update for the existing 0.2.2 runtime.
