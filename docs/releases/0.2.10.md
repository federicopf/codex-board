# Codex Board 0.2.10 / mobile 0.2.4

2026-10-17

Desktop and mobile now edit existing automations and category pipelines: name, prompt, target task/categories and all supported schedule types. Changes save to the same backend record, preserving identity, paused state and execution history. Editing only metadata preserves the next scheduled occurrence; interval/calendar changes recalculate the next run. Existing one-off dates can remain unchanged even after completion.

Calendar edits preserve the saved timezone across devices. Unchanged precise dates retain their original timestamp precision. Pipeline delay/destination edits retain time already spent in the source category; changing the source resets tracking.

Edits are serialized with scheduler submission. Already queued/running work is not cancelled or rewritten. Failed saves keep the form open and update persistence before replacing in-memory state.

Mobile 0.2.4 retains runtime 0.2.2 for compatible Android OTA delivery on preview. Editing requires desktop 0.2.10; older gateways show an upgrade explanation instead of deleting/recreating the workflow. The global concise automation-report policy from 0.2.9 remains active.
