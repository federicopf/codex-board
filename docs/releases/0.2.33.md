# Codex Board 0.2.33 / mobile 0.2.8

- Projects can be archived from their existing actions menu and restored from an expandable archived section at the bottom of the project list on desktop and mobile.
- Archived projects retain conversations, customers, names and files. General and new-conversation project pickers show active projects only.
- The archive state is shared by the Windows backend and mobile app. The mobile OTA keeps runtime 0.2.2 for compatible installed binaries; the new archive endpoint requires the 0.2.33 Windows backend.
