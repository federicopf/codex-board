# Codex Board 0.2.8 / Mobile 0.2.3

2026-10-17

## Mobile update

- Project selection is the entry screen, with search, the last workspace and an optional all-projects overview.
- Project boards use compact headers, readable conversation cards and contextual action menus.
- Back navigation follows conversation, board and projects. Android modal back handling is explicit.
- Consistent Ionicons replace text symbols. Technical chat activity is collapsed by default.
- Mobile layouts accommodate narrow screens and low-height windows.

## Shared model preferences

Desktop 0.2.8 shares model, reasoning effort, summary and service tier through the authenticated gateway. Partial updates use the persistence lock; board edits preserve preferences. Both clients serialize saves and ignore stale responses.

Desktop preferences are migrated without replacing newer shared selections. Mobile remains usable with older gateways: it inherits conversation defaults or saves explicit choices on the phone. Cross-device preference synchronization requires desktop 0.2.8.

## OTA compatibility

- Mobile app/source version: `0.2.3`.
- Android target channel: `preview`.
- Native runtime stays `0.2.2`, matching the distributed preview APK.
- Ionicons is JavaScript plus a font asset; the APK already contains the required Expo Font native module.
- The Windows backend cannot be delivered through an Expo OTA update.

Validation includes frontend and Rust regression tests, desktop build, mobile typecheck, Android export and browser previews with fixture data. Native phone interaction remains a separate check.
