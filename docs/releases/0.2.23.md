# Codex Board 0.2.23

2026-10-25

Automation start acknowledgements that time out are now treated as uncertain instead of failed when Codex may already have accepted the turn. The run remains correlated with its eventual completion and is not automatically duplicated.

Mobile chat opens from a locally cached recent page and refreshes in the background. History pages omit inline image payloads, cap very long text, reuse rollout paths discovered from the thread list, and resolve WSL mounted-drive paths without starting WSL.

The mobile project board now uses a compact project/customer selector modal for generic project threads and customer-owned conversations, with create and delete actions grouped inside the selector. These mobile changes target the existing 0.2.2 OTA runtime.
