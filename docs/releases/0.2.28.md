# Codex Board 0.2.28

2026-11-02

Projects can now be renamed on desktop and mobile without changing their folder, customers, or conversations. Names are shared through the Windows gateway and survive board refreshes and stale configuration writes.

Desktop shows a rename action in the project sidebar; mobile shows it in each project's actions menu. The mobile UI change is in source only until a separate OTA update is published. The Windows installer includes the new backend endpoint.
