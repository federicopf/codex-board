# Codex Board 0.2.17 / mobile 0.2.8

2026-10-22

Automation reports now distinguish whether the requested objective succeeded from noteworthy warnings, recovered errors and follow-up items. Summaries are structured to explain what was done, the concrete result and what remains. Desktop and mobile show the summary and noteworthy items in separate sections.

Local WSL file paths are converted for Windows opening. If the associated application cannot open a file, Codex Board now falls back to revealing it in Explorer; any remaining opening error is shown in the chat instead of being silently ignored.

Mobile 0.2.8 retains runtime 0.2.2 for OTA compatibility with existing Android preview and production builds.
