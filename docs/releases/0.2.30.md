# Codex Board 0.2.30 / mobile 0.2.8

- New chats choose their model before the first turn, with settings persisted per conversation.
- Automations are grouped by project/customer, and each card can run its workflow manually without changing the schedule.
- Removing a project now archives its active conversations and removes the project, customer metadata and custom label from the board, including when the project is empty. Local files and archived Codex history are preserved.
- Mobile project/customer counts use visible conversations; chat caching and refresh traffic are bounded to reduce load and crashes.

Mobile OTA keeps runtime 0.2.2 for installed compatible binaries. The new automation run and project removal commands require the 0.2.30 Windows backend.
